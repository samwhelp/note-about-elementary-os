## 下載方式


### iso-download.sh

執行下面的指令，下載「[elementaryos-8.1-stable-amd64.20251211.iso](https://sgp1.dl.elementary.io/download/MTc2NjU1Nzc5Mw==/elementaryos-8.1-stable-amd64.20251211.iso)」。

``` sh
wget -c 'https://sgp1.dl.elementary.io/download/MTc2NjU1Nzc5Mw==/elementaryos-8.1-stable-amd64.20251211.iso' -O 'elementaryos-8.0-stable-amd64.20250902rc.iso'
```

> 關於「-c」指的是續傳
